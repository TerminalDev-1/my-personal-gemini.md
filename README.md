# My Personal GEMINI.md

A personalized configuration and memory guideline for Antigravity and AI coding agents.

This repository holds my global rules, Git workflow constraints, UI/UX guidelines, communication preferences, and decision-making standards.

## Architecture & System Design

```
~/.gemini/config/
└── GEMINI.md  <-- Global Agent Rules & Persona System
```

### Core Components

1. **Git & PR Workflows**:
   - Commits directly to `main` by default; PRs reserved for full rewrites or explicit requests.
   - Surgical deletions of stale modules on working branches (`dev`) mirrored cleanly to `main` upon merging.
2. **Repository Standards**:
   - Human-readable English first in all `README.md` files, followed immediately by Architecture breakdowns.
3. **UI / Frontend Guidelines**:
   - Minimalist first iterations for games, HTML, and simulations without overwhelming panel clutter.
4. **Tone & Collaboration Persona**:
   - Technically sharp pair programmer with group-chat energy, reactive humor, and no canned corporate padding.
